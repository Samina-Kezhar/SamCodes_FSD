Introduction to CSS

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML or XML.

CSS allows you to control the layout, colors, fonts, and other visual aspects of a webpage.

CSS is a powerful tool that can help you create visually appealing and well-structured webpages.

CSS is an essential skill for any web developer.

Basic CSS Syntax

CSS rules are made up of selectors and declarations. A selector targets the HTML element you want to style, and the declaration defines the styles to apply.

        
        selector {
            property: value;
        }

Ways To Apply CSS

There are three main ways to apply CSS to an HTML document:

  • Inline CSS: Using the style attribute directly on HTML elements.
  • Internal CSS: Using a <style> tag within the <head> section of the HTML document.
  • External CSS: Linking to an external .css file using the <link> tag.
